# Phase 0

Phase 0 acceptance requires a fixture to traverse the full pipeline; auditable transitions; event deduplication; valid no-signal output; Red Team for every S3; no T3-only S3; Ops Check rejection of unsourced numbers; versioned coverage and thesis; replay without overwrite; deterministic results; five artifacts; reversible Alembic migration; passing pytest; and an accessible minimal FastAPI surface.

The phase is intentionally limited to a deterministic harness using SQLite and fake adapters. It must not progress into real web/RSS/News API collection, Gmail or mail delivery, OpenAI/Anthropic or any other LLM, LangChain/LangGraph/CrewAI, vector databases, knowledge graphs, predictions, investment advice, automated trading, multi-agent discussion, frontend, user/auth/multi-tenant features, cloud deployment, Docker orchestration, Redis/Celery, or commercial features.
